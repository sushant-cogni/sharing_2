### Personal 

    1. Basic Profile Information

    Profile avatar upload (image crop + preview)
    First name
    Last name
    Display name / public name
    Email address (verified badge)
    Phone number (OTP verification)
    Date of birth (optional)
    Gender (optional / configurable)

    2. Address & Location

    Country
    State / Region
    City
    ZIP / Postal code

    3. Professional / Organizer Info (Role‑based)

    Organization name
    Role / designation
    Company website
    Bio / description (markdown support optional)


### Payment 
    1. Saved Payment Methods

    Credit / Debit cards
    
    - Masked card number
    - Expiry date
    - Card brand
    UPI IDs
    Bank Acount Details
    Default payment method selector
    Add / Remove payment method

    2. Transactions & History

    Payment history table

        Date
        Event name
        Amount
        Transaction (Credited / Debited)
        Status (success / failed)


    3. Subscriptions & Plans (If applicable)

    Current plan (Free / Pro / Enterprise)
    Renewal date
    Usage limits
    Upgrade / downgrade plan
    Cancel subscription
