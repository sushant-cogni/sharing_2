## Setup

### 1️⃣ The Modern Way (Vite): Faster, leaner, and preferred for MERN.

```Bash
npm create vite@latest my-react-app <NAME / .>
cd my-react-app
npm install
npm run dev
```

### 2️⃣ The Legacy Way (CRA):

```Bash
npx create-react-app <NAME / .>
```

---

## Commands

| Command                 | Purpose                                                |
|-------------------------|--------------------------------------------------------|
| npm install            | Installs all dependencies listed in `package.json`.     |
| npm run dev            | Starts the local development server (e.g., Vite).       |
| npm run build          | Creates a compressed production build (for MERN deploy).|
| npm install `<package>`| Installs a new library (e.g., axios, react-router-dom). |

## The Virtual DOM Workflow:

- **State Change**: User clicks "Delete Product".

- **Re-render**: React creates a new Virtual DOM tree.

- **Diffing**: React compares the New Tree vs. the Old Tree.

- **Reconciliation**: React calculates the minimum steps needed to update the Real DOM.

- **Update**: Only the "Delete" button/row changes in the browser.

```Plaintext
[ Data / State ]  ───►  [ Virtual DOM (Blueprint) ] 
                                │
                                ▼
                        [ Diffing Engine ] <── (Compares old vs new)
                                │
                                ▼
                        [ Real DOM (Browser) ] <── (Only updates the delta)
```
