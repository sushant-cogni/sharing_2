# React Components

## The Concept 

### What is a component?
A component is a reusable, self-contained piece of UI logic (structure + behavior + styles) that returns React elements (usually via JSX). Think of components as custom HTML tags with superpowers: they accept inputs (props), manage state (if needed), and render UI.

### Why do components exist in React?
Separation of concerns by feature, not by file type—JS, markup, and styles live together as a cohesive unit.
Reusability & composition—you build small units and compose them into complex UIs.
Predictable updates & testability—UI is a pure function of state + props.

### What problem do they solve?
They solve UI complexity at scale: predictable rendering, consistent data flow (top → down), and efficient updates through React’s reconciliation (diffing) + commit process.

### Two types of components in React:

1. **Function Components (modern, preferred):**     
    Plain functions returning JSX; use hooks for state, effects, context, refs.
2. **Class Components (legacy but still found):**
    
    ES6 classes extending React.Component; use lifecycle methods and this.setState.

## ⚙️ The Syntax 

### 1) Function Component (Modern, Preferred)
``` JSX
// src/components/Greeting.jsx
import React from 'react';

export function Greeting({ name }) {
  return <h2>Hello, {name}!</h2>;
}

// Default export variant (only one default allowed per file)
// export default Greeting;
```

Using it internally (same file):

```jsx
function App() {
  return (
    <div>
      <Greeting name="Sushant" />
    </div>
  );
}
```

Using it from an external file:

```jsx
// src/App.jsx
import React from 'react';
import { Greeting } from './components/Greeting'; // named import
// import Greeting from './components/Greeting'; // default import variant

export default function App() {
  return <Greeting name="Team React" />;
}
```

Mounting into the DOM (the “tree”):
```jsx
// src/main.jsx (Vite) or src/index.js (CRA)
import React from 'react';
import { createRoot } from 'react-dom/client';
import App from './App';

createRoot(document.getElementById('root')).render(<App />);
```
---
### 2) Class Component (Legacy/Existing Codebases)

```jsx
// src/components/GreetingClass.jsx
import React from 'react';

export class GreetingClass extends React.Component {
  render() {
    const { name } = this.props;
    return <h2>Hello, {name}!</h2>;
  }
}
```

Using it:

```JSX
import React from 'react';
import { GreetingClass } from './components/GreetingClass';

export default function App() { 
    return <GreetingClass name="Enterprise Team" />;
}
```

## Import & Export Summary

**Named export:** export function X() {} → Import with braces: import { X } from './X'

**Default export:** export default X; → Import without braces: import X from './X'

Avoid mixing unless you have strong reasons; use one pattern consistently per file.

## Using & Outputting Dynamic Values

Template expressions in JSX:

```jsx
const name = 'Sushant';
const unread = 3;
const style = { color: unread ? 'tomato' : 'gray' };

<h1 style={style}>Welcome, {name}! {unread > 0 && <em>({unread} new)</em>}</h1>
```
Conditional class names & attributes:

```jsx
const isActive = true;
<button
  className={`btn ${isActive ? 'btn--primary' : 'btn--ghost'}`}
  aria-pressed={isActive}
  data-count={unread || undefined} // omit attribute when falsy
>
  Inbox
</button>
```

Spread for dynamic HTML props (careful with overrides):

```jsx
const baseProps = { role: 'img', width: 48, height: 48 };
<img src={src} alt={alt} {...baseProps} width={64} /> // last wins
```

## Setting HTML Attributes Dynamically & Loading Images

Dynamic attributes (boolean, data-*, etc.):
```jsx
<div
  title={`User: ${user.name}`}
  data-role={user.role}
  hidden={!user.isVisible}
/>
```

Loading images (module import – recommended with bundlers):
```jsx
import product from '../assets/product.png';
<img src={product} alt="Product" />
```

Loading images (public folder):
```jsx
// CRA: put image in public/, reference absolute path
/brand/logo.svg

// Vite: resolve relative to this module file (bundler-safe)
const imageUrl = new URL('../assets/photo.jpg', import.meta.url).href;
<img src={imageUrl} alt="Photo" />
```

External URLs + conditional attributes:

```jsx
const src = user.avatarUrl || '/avatar-fallback.png';
<img
  src={src}
  alt={`${user.name}'s avatar`}
  {...(src.startsWith('http') ? { referrerPolicy: 'no-referrer' } : {})}
/>
```

## How a Component Is Added into the Tree & Turned Into HTML the Browser Understands

- **Your code (JSX) →**Babel/TypeScript compiles JSX into React.createElement calls (or JSX runtime) that produce React elements (plain JS objects describing UI).

- **Render phase →** React walks the element tree to build/update the Fiber tree (its internal representation containing state, effects, and links).

- **Reconciliation →** React compares the new element tree with the previous tree to decide what changed (using key to maintain identity).

- **Commit phase →** React applies the minimal set of DOM mutations (create/remove/update nodes, attributes, event listeners).

- **Browser pipeline →** The browser updates DOM → Style (CSSOM) → Layout (reflow) → Paint/Composite to display pixels.


**Rule of thumb:** *Rendering (calculating what the UI should look like) is pure. Only the commit phase touches the real DOM. That’s why React rendering is predictable and testable.*

## Quick Reference: Creating & Accessing Components (Both Types)

### Function Component

```jsx
// create
export function Card({ children, elevated = false }) {
  return <div className={`card ${elevated ? 'card--elevated' : ''}`}>{children}</div>;
}

// internal use
function App() {
  return <Card elevated>Content</Card>;
}

// external use
import { Card } from './components/Card';
```
### Class Component

```jsx
import React from 'react';

export class CardClass extends React.Component {
  render() {
    const { children, elevated = false } = this.props;
    return <div className={`card ${elevated ? 'card--elevated' : ''}`}>{children}</div>;
  }
}

// external use
import { CardClass } from './components/CardClass';
```
